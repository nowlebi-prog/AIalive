# 🎤 커버용 음원 분리기

원곡 하나를 넣으면 이렇게 나눠 줍니다.

| 파일 | 내용 |
|---|---|
| `1_MR` | 반주 (보컬 전부 제거) |
| `2_메인보컬` | 리드 보컬만 |
| `3_백보컬` | 화음 / 코러스만 |
| `4_보컬전체` | 메인 + 백보컬 |
| `5_MR+백보컬` | 반주 + 백보컬 합본 (커버 녹음할 때 이걸 틀고 부르면 됨) |
| `6~8` | (옵션) 드럼 / 베이스 / 기타악기 |

## 설치 (처음 한 번)

1. 이 폴더를 원하는 곳에 둡니다. **경로에 한글이 없는 곳**이 안전해요. 예: `C:\stem-splitter`
2. `install.bat` 더블클릭
   - Python 3.11이 없으면 자동으로 설치해요. 설치 후 "한 번 더 실행하라"고 나오면 다시 실행하세요.
   - PyTorch GPU 버전(약 2~3GB)을 받기 때문에 10분 넘게 걸릴 수 있어요.
3. 마지막에 `GPU 인식: True ...`가 나오면 성공이에요.

## 사용

1. `run.bat` 더블클릭 → 브라우저가 자동으로 열림
2. 원곡 파일 끌어다 놓기 → **분리 시작**
3. 결과는 화면에서 바로 들어보거나, `결과\곡이름\` 폴더에서 꺼내 쓰세요.

처음 한 번은 AI 모델(곡당 약 1GB)을 다운로드하느라 오래 걸려요. 그다음부터는 GPU 기준 한 곡에 1~2분 정도예요.

## 팁

- **백보컬이 잘 안 나뉠 때**: `설정` → 2단계 모델을 다른 걸로 바꿔서 다시 돌려 보세요. 곡마다 잘 맞는 모델이 달라요.
- 메인과 똑같은 음으로 겹쳐 부른 더블링 백보컬은 어떤 모델로도 완벽히 나누기 어려워요.
- 유튜브 업로드용 MR은 `wav`나 `flac`로 뽑는 걸 추천해요. 음질 손실이 없어요.

## 문제 해결

- **GPU를 못 찾는다고 나옴**: NVIDIA 드라이버를 최신으로 업데이트한 뒤 `venv` 폴더를 지우고 `install.bat`을 다시 실행하세요.
- **그래픽 메모리 부족(CUDA out of memory)**: 설정에서 `MDX-Net` 계열(빠름) 모델을 선택하세요.
- **mp3를 못 읽음**: 인터넷이 연결된 상태에서 처음 실행해야 ffmpeg가 자동으로 받아져요.
